# 📱 Device Deck

Device Deck is a **Mobile Shop Management System** developed to help manage products, inventory, and day-to-day shop operations through a web-based admin interface.

## ✨ Features

* Product management
* Inventory management
* Admin dashboard
* Product information management
* User authentication
* Responsive web interface

## 🛠️ Technologies Used

* **PHP**
* **MySQL**
* **HTML**
* **CSS**
* **Bootstrap**
* **JavaScript**

## 🎯 Purpose

This project was created as a practical web development project to understand how a database-driven management system works, including CRUD operations, authentication, and MySQL database integration.

## 💻 Running the Project

The project is designed to run locally using **XAMPP** with Apache and MySQL.

> This project was developed for local use and learning purposes.
